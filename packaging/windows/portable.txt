LayerShop portable mode

While this file sits next to photocraft.exe, LayerShop keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the LayerShopData folder beside it, and writes
nothing to %APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move LayerShop with its settings.

Delete this file to use the normal per-user folders instead: %APPDATA%\LayerShop for settings
and %LOCALAPPDATA%\LayerShop\Recovery for crash-recovery autosaves. If LayerShopData can't be
written (for example on a read-only drive), LayerShop says so and uses those folders instead.
